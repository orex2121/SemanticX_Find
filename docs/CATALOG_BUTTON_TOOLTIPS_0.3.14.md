# Catalog button tooltips — 0.3.14-alpha

На вкладке «Каталоги» добавлены подробные всплывающие подсказки для всех кнопок:

- добавление и настройка каталога;
- инкрементальное обновление и полное пересоздание индекса;
- удаление каталога из приложения;
- пауза и отмена индексации;
- сброс фильтра и поиск дубликатов;
- открытие файла или папки и копирование полного пути.

Подсказки поясняют последствия действий. В частности, удаление каталога из приложения не удаляет исходные файлы и индекс на диске, а обычное обновление пропускает уже готовые неизменённые файлы.

Тексты локализованы для русского, английского, французского и испанского языков.
