# Persistent favorites — 0.2.12-alpha

- A selected search result can be added to or removed from favorites using the action button or context menu.
- Favorite search results are marked with a star.
- The Favorites tab lists saved files independently of current search results.
- Favorite files can be opened, revealed in Explorer, copied as a full path, or removed from the list.
- Missing favorite files remain visible with a warning marker so the user can remove or investigate them.
- Favorites are stored in the portable application settings and survive restarts.
