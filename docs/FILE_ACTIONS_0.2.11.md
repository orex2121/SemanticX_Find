# File actions and context menus — 0.2.11-alpha

- Search results and catalog files open on double-click.
- Both lists have right-click context menus.
- Available result actions: open file, reveal in Explorer, copy full path, copy filename, copy folder path, and show in catalog.
- Catalog-file actions include open, reveal, and all three copy variants.
- New action labels are localized in English, Russian, French, and Spanish.
