# Catalog summary and window state — 0.2.6-alpha

- The Catalogs tab now displays a localized human-readable summary instead of raw JSON.
- The summary includes availability, file/chunk/error counts, last indexing time, extensions, visual-indexing state, and index location.
- Indexed files are listed with status, chunk count, and an error message when applicable.
- “Show in Catalog” uses the same readable presentation for filtered search results.
- Application window size, position, and maximized state are restored on the next launch.
