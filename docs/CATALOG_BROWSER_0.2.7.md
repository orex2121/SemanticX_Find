# Catalog file browser — 0.2.7-alpha

- Catalog statistics and indexed files are displayed in separate areas.
- Selecting a catalog loads a selectable list of its indexed files.
- The selected catalog file can be opened, revealed in Explorer, or copied as a full path.
- Double-clicking an indexed file opens it.
- “Show in Catalog” from search results populates the same browser with the filtered result set.
- The statistics view always scrolls back to its first line when refreshed.
