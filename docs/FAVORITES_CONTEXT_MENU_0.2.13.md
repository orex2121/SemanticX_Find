# Favorites context menu — 0.2.13-alpha

- Favorite files now have the same right-click file actions as search results.
- Actions include open, reveal in Explorer, copy full path, copy filename, copy folder path, and show in catalog.
- “Show in Catalog” selects and filters the owning registered catalog when one exists.
- Removing the entry remains available after a menu separator.
- A localized status message explains when a favorite is outside all registered catalogs.
