# Minimized launcher and image previews — 0.2.4-alpha

Дата проверки: 7 октября 2026, Windows.

## Изменения

- `Start.bat` повторно запускает себя в минимизированном окне `cmd`, после чего
  исходная консоль закрывается. При ошибке минимизированную консоль можно
  восстановить из панели задач и прочитать диагностику.
- Прикреплённые изображения показываются как горизонтальная прокручиваемая
  лента карточек.
- Каждая карточка содержит миниатюру с сохранением пропорций и сокращённое имя.
- Полный путь доступен во всплывающей подсказке.
- Лента одинаково обновляется для файлового диалога, drag-and-drop, вставки из
  буфера и встроенного снимка экрана; после очистки она скрывается.
