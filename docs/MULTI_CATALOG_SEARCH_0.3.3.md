# Multi-catalog search selection — 0.3.3-alpha

The catalog scope field is now a checkable multi-select list.

- All catalogs are selected by default.
- The **All catalogs** item checks or clears every catalog in one action.
- Any combination of individual catalogs can be selected.
- One selected catalog is displayed by name; multiple selections are displayed as a count.
- Hovering the closed selector shows the complete selected-catalog list.
- The selection survives interface rebuilds such as language or theme changes.
- Clearing every checkbox intentionally searches no catalogs and returns an empty result set.
