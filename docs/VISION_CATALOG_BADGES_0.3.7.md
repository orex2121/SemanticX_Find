# Vision catalog badges — 0.3.7-alpha

- A green circular **V** is shown to the left of a catalog path on the Catalogs tab when its saved index identity has `visual: true`.
- The search-page catalog checklist shows the same **V** at the right edge of the corresponding catalog row, leaving the selection checkbox on the left.
- The badge represents the index that was actually built, not merely the catalog's current Vision setting.
- A missing index, a text-only index, or Vision enabled without rebuilding does not receive the badge.
