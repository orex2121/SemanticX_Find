# Catalog layout — 0.3.15-alpha

Вкладка «Каталоги» получила трёхколоночную компоновку:

- слева во всю доступную высоту расположен список добавленных каталогов;
- справа рядом друг с другом расположены информация о выбранном каталоге и список индексированных файлов;
- ширина колонок регулируется двумя подвижными разделителями.

Все три поля получили заголовки. Кнопки «Сбросить фильтр поиска» и «Найти дубликаты» удалены с вкладки.
