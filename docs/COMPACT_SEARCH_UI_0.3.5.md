# Compact search UI — 0.3.5-alpha

- Option headings and explanations now share one compact line.
- Long labels were shortened while full text remains available as a tooltip.
- The Path, ComfyUI node, and ComfyUI model filters were removed from the desktop search page.
- Search query, Search button, and Catalog selector use a blue primary-action accent.
- Screenshot uses a green accent so it stands out from auxiliary image actions.
- Core engine and CLI filters remain available internally; only the unnecessary desktop controls were removed.
