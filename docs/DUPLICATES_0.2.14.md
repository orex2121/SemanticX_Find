# Duplicate browser — 0.2.14-alpha

- The Catalogs tab can display duplicate files for the selected indexed catalog.
- Duplicate identity is based on the full SHA-256 content hash stored during indexing, not filename or size alone.
- Results are grouped and show relative paths and file sizes.
- Standard catalog-file actions remain available for duplicate entries.
- The feature is read-only: SemanticX Find never deletes duplicate source files automatically.
