# Этап 1 — Desktop 0.2.0-alpha, 7 октября 2026

Добавлены фильтры по расширению, части пути, узлу, модели и минимальной оценке. Общий лимит выдачи применяется ко всем каталогам. Новые параметры каталога: подпапки, скрытые файлы, максимум МБ, локальный/центральный/автоматический индекс. Повторное добавление папки блокируется.

Исправлен жизненный цикл QThread: результат обрабатывается после finished, ссылки на завершённые задачи удаляются, callback может безопасно запустить следующую задачу. Отмена не передаёт словарь в обработчик результатов. Пока работа идёт, повторная индексация не заменяет объект управления текущей задачей. При пустой выдаче очищаются старые подробности.

При перестроении окна сохраняются запрос, фильтры, вкладка, каталог и изображения. Ctrl+K обращается к текущему полю, а не к удалённому. Добавлены system/light/dark, batch size, лимит результатов, EXE icon для окна, локализованные названия сигналов. Все новые UI строки EN/RU/FR/ES.

## Воспроизведение

Linux/offscreen: `QT_QPA_PLATFORM=offscreen PYTHONPATH=. python -m pytest tests -q`
Результат: **18 passed**, полный вывод logs/stage1-tests.log. PySide6 6.11.2 установлен в тестовой среде. Снимок: docs/screenshots/stage1-search.png. Воспроизведение: `python scripts/desktop_preview.py`.

Использованы 4 настоящих ComfyUI JSON из tests/fixtures; исходные URL и SHA256 в SOURCES.json. Код custom nodes не выполняется. 6 GUI тестов проверяют сохранение состояния, смену языка/темы, ошибки/retry, отмену, цепочку QThread и реальный workflow поиск с фильтром.

## Ограничения

Это alpha, не готовая v1.0. GUI проверен offscreen Linux, не Windows или RTX 5090. Нет собранного EXE, runtime, весов Gemma/OCR. Системная тема зависит от поддержки Qt/OS. Подробности каталога пока технический JSON. Не завершены ANN, tokenizer-aware chunks, полноценная локализация ошибок и руководства, Windows/GPU/mixed-DPI проверки. Следующий этап: исправить filename baseline и добавить воспроизводимое сравнение режимов ранжирования.
