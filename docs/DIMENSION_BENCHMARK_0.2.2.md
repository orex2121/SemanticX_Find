# Embedding dimension benchmark — 0.2.2-alpha

Дата: 7 октября 2026. Платформа: Windows, NVIDIA GeForce RTX 5090,
CUDA 13.0, BF16, batch size 32. Модель: EmbeddingGemma 2, ревизия
`914f7f89142e33e77833254d9c9b90c3cef7303b`.

Одинаковый анонимизированный набор из четырёх публичных ComfyUI workflow и
шести размеченных запросов был отдельно проиндексирован в 256D и 768D.

| Метрика | 256D | 768D |
|---|---:|---:|
| Файлы / chunks | 4 / 231 | 4 / 231 |
| Ошибки индексации | 0 | 0 |
| Hybrid MRR | 1.0 | 1.0 |
| Hybrid Recall@5 | 1.0 | 1.0 |
| Медиана запроса | 0.047 с | 0.0465 с |
| Размер тестовой SQLite БД | 0.53 MiB | 1.06 MiB |

На этом малом наборе 768D не улучшил качество и примерно удвоил общий размер
SQLite БД. Рекомендованное значение по умолчанию — **256D**. 768D следует
повторно оценить на большом и разнообразном пользовательском каталоге; данный
smoke benchmark не доказывает равенство качества на реальных масштабах.
