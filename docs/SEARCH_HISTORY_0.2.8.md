# Search history — 0.2.8-alpha

- The search bar includes a localized recent-query selector.
- Text queries are saved in the portable application settings.
- Selecting a previous query restores it to the search field.
- History is limited to the 20 most recent unique queries; duplicates are moved to the top.
- “Clear history” removes all stored queries.
- Empty and image-only queries are not added to text history.
